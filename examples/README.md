Examples
========

This folder contains examples of how to use Crappy. Most of them can be run
without any specific hardware, but some require additional Python modules.

- **blocks** contains one or more usage examples for each Block in Crappy. Look
  here to learn how to use a specific Block.
- **custom_objects** contains examples of how to instantiate and use custom
  objects in Crappy. Look here to learn how to implement your own features and
  hardware.
- **vision_blocks** contains examples of independent image-acquisition,
  processing, display, and recording Blocks, as well as custom VisionBlock
  implementations. Look here to learn how to build image pipelines using
  ImageLinks.
- **fake_tests** contains examples that use the ``FakeMachine`` Block.
- **modifiers** contains a usage example for each ``Modifier`` object. Look
  here to learn how to use ``Modifier`` objects.
- **other_examples** contains examples that require third-party hardware and
  therefore cannot be run directly by most users.
- **real_setups_scripts** contains scripts used by researchers at the LaMcube
  laboratory in real-world setups.
