======
Blocks
======

The Block API is grouped by role. Each category begins with a compact class
summary and then documents the supported methods for each object.

:doc:`ordinary_blocks`
  Data acquisition, control, display, recording, coordination, and all-in-one
  image Blocks.

:doc:`vision_blocks`
  Composable image acquisition, processing, display, and recording stages.

:doc:`generator_paths`
  Command segments used by the Generator Block.

:doc:`camera_processes`
  Advanced processing helpers managed by all-in-one Camera Blocks.

:doc:`block_base`
  The base class and Link methods used to implement custom Blocks.
