=============
Release notes
=============

This documentation describes Crappy |release|. Release notes are maintained on
GitHub so that each version has one authoritative change history.

Use the `GitHub release archive
<https://github.com/LaboratoireMecaniqueLille/crappy/releases>`_ to read the
notes for published versions and download their source archives or wheels. A
version still under development does not appear there until it is released.
