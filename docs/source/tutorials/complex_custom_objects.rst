====================================
Advanced custom-object guides moved
====================================

The former combined advanced tutorial has been split into shorter guides.
Choose the task that matches the experiment:

- :doc:`custom_generator_path` defines a reusable command profile.
- :doc:`custom_inout` covers regular acquisition, commands, and zeroing.
- :doc:`custom_streaming_inout` retrieves high-rate measurements in chunks.
- :doc:`custom_actuator` covers motion control, including position-mode speed.
- :doc:`custom_camera` covers Camera settings, regions of interest, triggers,
  and image metadata.
- :doc:`custom_vision_block` adds a reusable image stage. VisionBlocks are
  recommended for new image pipelines.
- :doc:`custom_all_in_one_camera` adds processing inside an all-in-one Camera
  Block. This architecture remains supported and is not planned for
  deprecation.

The :doc:`custom_objects` landing page links the complete set of customization
guides. Use :doc:`../concepts/choosing_custom_object_type` when the appropriate
object type is unclear.
