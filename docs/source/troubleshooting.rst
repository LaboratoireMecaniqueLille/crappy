===============
Troubleshooting
===============

Search this documentation for the error message or affected component first.
If it does not contain an answer, check for related reports in the
`Issues <https://github.com/LaboratoireMecaniqueLille/crappy/issues>`_ and
`Discussions <https://github.com/LaboratoireMecaniqueLille/crappy/discussions>`_
sections of our GitHub page.

If the problem has not been reported, you can
`open a new issue <https://github.com/LaboratoireMecaniqueLille/crappy/issues/new/choose>`_
on the GitHub page. Alternatively, `open a new discussion
<https://github.com/LaboratoireMecaniqueLille/crappy/discussions/new/choose>`_
for usage questions. A bug report should include the Crappy and Python
versions, operating system, relevant hardware and backend, a minimal script,
and the complete error traceback. You can also attach the log file, located at
``/tmp/crappy/logs.txt`` on Linux
and macOS, or at ``C:\Users\<User>\AppData\Local\Temp\crappy\logs.txt`` on
Windows.
